Creator workflow

Everything around publishing, without the clutter.

WeTube is designed to reduce repetitive channel work while keeping important YouTube actions visible and under the creator’s control.

↑

Video publishing

Upload videos to an authorized channel and set title, description, category, privacy status and other supported metadata before publishing.

▤

Content management

Review and manage uploaded videos, playlists and channel-related information through one organized workspace.

◫

Multiple authorized channels

Work with channels explicitly connected through Google OAuth. WeTube never asks for or stores a YouTube password.

✓

Explicit user actions

Upload, update and visibility-changing actions are presented to the user before execution. The connected channel remains in control.

↻

Current channel data

Where channel information is displayed, WeTube uses YouTube API Services and refreshes stored API data as required by applicable policies.

⌁

Focused creator tools

A streamlined interface built around legitimate creator workflows rather than recreating the YouTube viewing experience.

Privacy & control

Your channel stays yours.

WeTube uses Google OAuth 2.0 to request only the permissions needed for enabled features. You can revoke WeTube’s access from your Google Account at any time.
